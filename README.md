# Kotlin Multiplatform app template

[![official project](http://jb.gg/badges/official.svg)](https://confluence.jetbrains.com/display/ALL/JetBrains+on+GitHub)
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

This repository now showcases a basic authentication flow built with Compose Multiplatform for Android and iOS. The shared
module exposes login and registration logic with a simple in-memory user store to mirror the authentication plugin generated by
Android Studio.

### Technologies

The app uses the following multiplatform dependencies in its implementation:

- [Compose Multiplatform](https://jb.gg/compose) for UI
- [Koin](https://github.com/InsertKoinIO/koin) for dependency injection
- [AndroidX Lifecycle](https://developer.android.com/jetpack/androidx/releases/lifecycle) runtime for Compose state collection

> These are just some of the possible libraries to use for these tasks with Kotlin Multiplatform. You can find a wide variety of curated multiplatform libraries in the [kmp-awesome](https://github.com/terrakok/kmp-awesome) repository.
